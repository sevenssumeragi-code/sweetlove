# 07 Opus執筆用仕様書（シナリオ追加・加筆のための指示書）

このドキュメントは、後からClaude Opusにシナリオを加筆・拡張させるときに、そのままプロンプトに貼って使える仕様書です。

---

## 1. 執筆の前に必ず読むもの

1. `docs/01_物語設計書_大筋と章構成.md` — 隠された真実（第4節）は**全ルート共通の正解**。絶対に変えない。
2. `docs/02_キャラクター設定と感情曲線.md` — 口調早見表（第0節）を厳守。
3. `docs/04_伏線配置・回収表.md` — 新しい伏線を置いたら必ずこの表に追記し、回収場所を決めてから書く。
4. 加筆する章のシナリオファイル（`game/scenario/*.js`）の前後。

## 2. スクリプト書式（DSL）

シナリオは `game/scenario/NN_name.js` に、次の形で書く。

```js
NovelCore.add('ファイル名', String.raw`
# コメント
*ラベル名
@bg 背景ID
テキスト（地の文）
キャラ名「台詞」
`);
```

- **1行＝1クリック**。地の文は1〜2文ごとに改行する。
- テンプレート文字列なので、本文にバッククォート（`）と `${` は使わない。
- 主人公の名前は `{name}`（例：`ネオ「……頼む。{name}」`）。主人公の台詞は話者名を付けず `「……」` とだけ書く（夢小説型）。
- 話者名に使えるのは：`{name}` レニィ ヒュウ ジンパチ ムニ ゲル ネオ ハル ソラ 渡会 あおい 鳳源一郎 久我 綾小路麗華 鷹取しず レニィの母 大貫。それ以外は地の文で `「……」` と書く。
- 話者名の後の「」の前にスペースを入れない。話者名に「、」「。」を含めない。

### 命令一覧

| 命令 | 書式 | 説明 |
|---|---|---|
| ラベル | `*label_name` | ジャンプ先。英数字と_。ファイルをまたいで一意 |
| 章 | `@chapter ch05 第五章　タイトル` | 章タイトルカード表示・オートセーブ・フローチャート記録 |
| シーン | `@scene c5_roof シーン名` | フローチャートの節点。1場面に1つ |
| 背景 | `@bg id` | `manifest.js` の bg に登録が必要 |
| BGM | `@bgm id` ／ `@bgm stop` | |
| 効果音 | `@se id` | |
| 立ち絵 | `@show キャラID 表情 [位置]` | 位置：left lc center rc right。表情は manifest の exprs から |
| 立ち絵消去 | `@hide キャラID` ／ `@hide all` | |
| スチル | `@still id` ／ `@still off` | 表示した瞬間にギャラリー回収 |
| 演出 | `@effect shake｜flash｜black｜white｜red` | |
| 待機 | `@wait 500` | ミリ秒 |
| 手紙 | `@letter` … `@endletter` | 間の行を便箋ウィンドウに表示。`@clearletter` で改ページ |
| 変数 | `@set aff.reny+3 house-2 mem+1 tmp.x=0` | 空白区切りで複数可 |
| フラグ | `@flag F_XXX` ／ `@unflag F_XXX` | |
| ルート | `@route reny` | |
| 条件ジャンプ | `@if 式 -> ラベル` | |
| ジャンプ | `@goto ラベル` | |
| サブルーチン | `@call ラベル` … `@return` | 三角関係イベント等 |
| ヒント | `@hint 文章` | ヒント帳「ちづるさんのメモ」に表示される今のアドバイス |
| エンディング | `@ending id` | `endings.js` に登録が必要 |
| 条件付き行 | `?[式] 任意の行` | その行（テキスト・命令どちらも）を式が真のときだけ実行 |

### 選択肢

```
@choice 問いかけ（省略可）
+ 選択肢の文 -> 飛び先ラベル | aff.jin+3 F_JIN_FEAR_KNOWN
+ [aff.gel>=8 && aff.jin>=8] 条件付き選択肢 -> ラベル | aff.gel+3 aff.jin+3 F_TRI_GJ
```

- 効果は `|` の後に空白区切り。`aff.X+n`／`house-n`／`F_FLAG`（立てる）／`!F_FLAG`（下ろす）／`変数=値`。
- 選択肢は2〜6個。**違う選択は必ず違う場面に飛ぶ**（同じラベルに飛ばすのは「言い方だけ違う」選択に限る）。

### 式

`aff.reny>=80 && F_RENY_SHARE`、`route=="jin"`、`!F_GEL_TRUTH`、`mem>=4`、`house<30`、`sys.endings>=5`、`tmp.fest==3`。使える変数：`aff.reny aff.hyu aff.jin aff.gel aff.neo aff.muni house mem route sys.endings tmp.*` と `F_*`。

## 3. 文体ルール

1. **一人称は主人公「私」**。過去形の地の文。心理描写を丁寧に、ただし説明ではなく出来事で見せる。
2. **情景描写を必ず入れる**：場面の頭で、光・音・匂い・温度のうち2つ以上。
3. **会話だけで進めない**：台詞3〜4行ごとに、表情・仕草・沈黙の描写を1行。
4. 感情が動く場面は、短い文で改行を多く。「――」と「……」は効果的に、乱用しない。
5. 各シーンの最後の1〜2行は「引き」：次が気になる一言、小さな違和感、または余韻。
6. 夢小説型：主人公の容姿の描写は最小限（黒髪のみ可）。
7. 恋愛描写は甘く、キャラの主題語（02第9節）を必ず台詞に入れる。
8. ムニとの関係は**家族**。恋愛的な語彙を使わない。
9. ゲルとの恋愛は、同性であることを本人が意識している描写を入れつつ、特別扱いも否定もしない。
10. ネオは「悪者っぽさ」を出さない。嫌味は不器用さの裏返しとして、直後に小さな優しさを置く。

## 4. 物語ルール（矛盾防止）

- 年齢・日付（`11_矛盾チェックリスト.md` の「確定事実」）を変えない。
- 十二通目の内容は第十二章より前に明かさない（断片・暗示は可）。
- 死亡してよいのは、ジンパチBAD（殉職）と共通BAD（主人公）のみ。ムニは絶対に死なない。
- レニィとムニを血縁にしない。ネオを悪人にしない。
- ルート外のキャラの状態は、全ルート共通の骨格（第九〜十二章）と矛盾させない。とくに：ネオの在不在（`F_NEO_BACK`）、ソラの在不在（`F_SORA_WAIT`）、ヒュウは第八章以降必ず家にいる（ヒュウBADの火事後を除く）。

## 5. 加筆の手順

1. どの章・どのラベルの間に入れるかを決める。
2. 新しい選択肢で好感度を動かす場合、1章あたり1キャラ最大+15程度に抑える（HAPPYの余裕は約10点。`simulate.js` で確認）。
3. 新しいフラグは `game/data/flags.js` に登録（入手場所・効果・未入手ヒント）。立てたら必ずどこかで参照する。
4. 新しい背景・スチル・BGM・SEは `game/data/manifest.js` に登録し、`desc` に発注内容を書く。
5. 新しいエンディングは `game/data/endings.js` に3段階ヒントと `sim`（攻略方針）付きで登録。
6. 検証：
   ```
   node tools/validate.js     # 構文・参照・口調・到達可能性
   node tools/simulate.js     # 全エンディング到達・攻略チャート再生成
   node tools/gen_docs.js     # 一覧ドキュメント再生成
   ```
   3つとも成功するまで直す。

## 6. 加筆の優先候補（さらに大長編化する場合）

| 優先 | 場所 | 内容 |
|---|---|---|
| A | 第一章〜第五章の各「誰と過ごす？」 | 各個別シーンを現在の10〜20行から30〜40行へ。二人きりの会話をもう一往復 |
| A | 第九章〜第十一章の個別ルート | 各ルートに日常イベントを1つずつ追加（冬の買い物、雪合戦、大学の試験勉強、港の初日の出） |
| B | 第六章と第七章の間 | ジンパチ不在の家の日常を1シーン（彼の大盛りのラベルを見つめるムニ） |
| B | 第十章 | 各ルートで「ソラの告白」を相手キャラがどう受け止めたかの会話 |
| C | エンディング | 各HAPPYに「1年後」のエピローグを追加 |

- 新しい伏線は置かない（または置いたら 04 に追記）
- 口調早見表を厳守（ゲルは一人称「私」、〜だな、「貴様」禁止）
- 書式は 07 のDSL。完了後 node tools/validate.js と node tools/simulate.js を実行し、エラー0を確認
