# 05 中盤の停滞防止と、終盤の反転・エンディング設計

## 1. 中盤（第四章〜第八章）の停滞防止策

恋愛ADVは「日常が続いて中だるみ」しがち。本作では次の7つの装置で防ぐ。

| # | 装置 | 具体例 |
|---|---|---|
| 1 | **毎月一日の手紙＝章の予告状** | 章の冒頭で必ず「この章で何かが起きる」と宣言される。日常シーンを読んでいても、プレイヤーは手紙の一文がいつ回収されるかを待っている（「花火が苦手な人がいます」「嵐の夜、あなたは何かを思い出す」） |
| 2 | **日常の中に異物を一つ** | 楽しい日常の最後に、必ず小さな違和感を置く：潮干狩りの後の児相の封書、祭りの後の黒い車、屋根の上の星空の後の火事の夢、停電のババ抜きの後の鐘 |
| 3 | **「安心→再危機」の二段構え** | 第三章：ムニ発見（安心）→ムニの絵の「ママ」（再危機の種）。第七章：ジンパチとの和解（安心）→台帳と殴打（再危機）。第八章：ヒュウ帰還（安心）→鳳源一郎と借金（再危機） |
| 4 | **謎の答えを小出しにする** | 夜の塔の灯り（序章）→レニィのひみつ基地（第二章）→鐘の正体（第七章）。答えるたびに、もっと大きな謎（15年前の火事）へ接続する |
| 5 | **主人公自身が謎になる** | 第六章で「私はこの家で一度死にかけていた」。中盤で視点が「住人たちの秘密」から「自分の過去」へ反転し、物語のギアが一段上がる |
| 6 | **関係を固定しない** | 第六章：ジンパチとの断絶、第七章：ジンパチ→ヒュウへの暴力、第八章：ヒュウ不在の食卓。仲良し七人の輪が、中盤で一度壊れる |
| 7 | **個別イベントの選択が毎章変わる** | 「誰と過ごす？」の選択肢は章ごとにシチュエーションが違い（潮干狩り／雨の午後／祭り／海／本当のことをひとつ／仮面舞踏会）、同じ相手でも毎回新しい面を見せる |

### 各章の「引き（続きが気になる終わり方）」

| 章 | 最後の一行（要旨） |
|---|---|
| 序 | 誰もいないはずの塔に、灯りがともっていた |
| 1 | 足音は、朝まで二度と動かなかった |
| 2 | 廊下の角で、小さな足音が止まった（ムニが面談の話を聞いていた） |
| 3 | 「ママ」のエプロンのポケットには、青い色鉛筆が一本 |
| 4 | 「丘の件」――黒い車が去っていく |
| 5 | 扉の向こうで、誰かが、私が泣き止むまで待っている |
| 6 | 『しばらく詰所に泊まる。探すな』 |
| 7 | 『千鶴さん、ごめんなさい』――六人になった凪ノ家 |
| 8 | 初雪の夜、会いに行くのは――（ルート分岐） |
| 9 | 七つ用意したケーキの皿のうち、一つが空いたまま |
| 10 | 各ルートの核心（母の知らせ／あおいの来訪／墓前／日記／東京／塔のかくれんぼ） |
| 11 | 二時の鐘。焦げ臭い。 |

## 2. 終盤の反転（「最悪」に見えて、さらに裏がある）

| # | 表の「最悪」 | 裏の真実 | 事前の伏線 |
|---|---|---|---|
| R1 | 主人公が火事の原因の一人だった（第六章の暗示） | 原因は二人の子どもの「星」で、誰も悪くない。剛は「誰のせいにもするな」と遺した | 蝋燭の幻、缶の星、夢の「みて、ほしだよ」 |
| R2 | ヒュウの母が放火犯（第七章、本人も認める） | あおいは子どもたちを守るため罪をかぶった | 「日向のせいじゃない」（誰も訊いていない）、記事の「可能性」という曖昧さ |
| R3 | ヒュウはあの夜、主人公を置いて逃げた（本人の告白） | 最初に燃えるカーテンから主人公をかばい、その火傷を負った。逃げたのはその後 | 雨の灯台・仮面の火傷、「痛いか、と訊かれたのは母以来」 |
| R4 | ネオが家を売った（第九章） | ネオは自分を売った。「譲渡」されるのは借金 | 九通目「自分を傷つける嘘」、LEDのろうそく、「頼む」 |
| R5 | ムニの母は子を捨てた | 生かすために手を離し、正体を隠して毎日プリンを作っていた | シナモン抜き、カップ、絵のエプロン |
| R6 | 手紙は超常の予言 | 祖母が毎日住人を見ていた愛情の結果 | 各手紙の具体性（ヒュウは必ず文句を言います） |
| R7 | 十二通目は書かれなかった | 書かれていた。持ち出したのは、宛名のもう一人（ヒュウ） | 序章で目を逸らすヒュウ、十一通目「二段目」 |
| R8 | ゲルは冷たい人 | 聞こえていないだけだった | 背中からの声、左側の席、唇を見る |
| R9 | レニィは怠け者 | 夜通しムニを守っていた | 油の指、布団の中の「昨日寝たの遅かった」 |
| R10 | 鳳源一郎は冷酷な買収者 | 千鶴の元教え子。「欲しいものは欲しいと言え」を奪うことと勘違いしていた | 時計塔を懐かしそうに見上げる |

## 3. 同じ夜の再演（第十一章）

15年前と同じ2月17日、同じ屋根裏、同じ缶の星、同じ星の窓。各ルートは「あの夜をやり直す」構造になっている。

| ルート | あの夜に欠けていたもの | 第十一章でのやり直し |
|---|---|---|
| レニィ | 起きている人（誰も気づかなかった） | 夜を半分こしていたから、起きていられた |
| ヒュウ | 逃げずに立つ勇気 | 「日向くん！」の声で、今度は逃げずに火を叩き消す |
| ジンパチ | 剛が「帰る」こと | 「いってらっしゃい、必ず帰ってきて」→怖がって、生きて帰る道を選ぶ |
| ゲル | 呼ぶ声に気づくこと | 主人公がゲルの「耳」になり、ガレージへ走る |
| ネオ | （ネオ自身は無関係）欲しいものを守る意志 | 高価な上着で火を押さえ、「この家は一つしかない」 |
| ムニ | 母の手 | ソラが自分の体で火を押さえ、初めて「ママ」と呼ばれる |

「見張らなかった」場合の本火事は、あの夜がそのまま繰り返される：レニィは眠り、ジンパチは父と同じ場所で倒れ、ゲルは聞こえず、ヒュウは再び火傷する。**手紙に従うことが、過去を書き換える唯一の方法**という構造。

## 4. エンディング設計（全27種）

- 各キャラ HAPPY／NORMAL／BAD ×6＝18
- 三角関係（甘い／苦い）×3組＝6
- 共通BAD（空き家／焔の夜）＝2
- TRUE（凪ノ家の灯）＝1

| 種類 | 設計方針 |
|---|---|
| HAPPY | そのキャラの「傷」の主題語で終わる（おはよう／両目で／いってきます／すき／家族になってくれ／ただいま） |
| NORMAL | 関係は温かいが、言葉にするのは「もう少し先」。後日談で未来を示唆し、ハッピーへの伏線にする |
| BAD | 死亡は2種のみ（ジンパチ殉職・主人公）。他は「失う」形のBAD：昏睡、失踪、無言の別離、王冠、忘却、空き家。いずれも序章〜中盤の台詞の反転で締める（「起こしてもらうの、好きなんだ」→起こす側に／「だれ？」→「……だれ？」） |
| 三角 甘い | どちらも選ばない「保留」を、三人が肯定する結末 |
| 三角 苦い | 「選ばない優しさ」が、二人を遠ざける結末 |
| TRUE | 恋愛の決着ではなく「家」の決着。主人公が相続を受け入れ、全員で集合写真。最後の一行は十二通目の最後の会話への返事 |

### エンディングと後日談の整合

HAPPY・NORMALのエンディングの後日談は、ルート外のフラグで分岐する定型文を持つ（`?[F_NEO_BACK]`／`?[F_SORA_RECONCILE]`）。これにより、どのエンディングでも「家はどうなったか」「ムニはどうなったか」が、プレイ内容と矛盾しない。
