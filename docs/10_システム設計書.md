# 10 システム設計書

## 1. 構成

```
game/
  index.html              画面レイヤー・UI・スクリプト読み込み順（＝シナリオのパース順）
  css/style.css           UI・プレースホルダ表示
  js/core.js              DSLパーサー・式評価・状態（ブラウザとNodeで共用）
  js/engine.js            実行エンジン・描画・音声フック・メニュー・セーブ・ヒント帳
  data/characters.js      キャラ表示名・プレースホルダ色・プロフィール
  data/manifest.js        背景・立ち絵・スチル・BGM・SEのパスと発注内容
  data/flags.js           重要フラグ定義（ヒント帳の「記憶のかけら」）
  data/endings.js         エンディング定義・3段階ヒント・シミュレータ方針・遊び方
  scenario/*.js           シナリオ本文（DSL）
  assets/{bg,chara,still,bgm,se}/   ← Codexが素材を置く場所
tools/
  lib.js                  Node用ローダーとヘッドレス実行器
  validate.js             静的検証
  simulate.js             動的検証・攻略チャート生成
  gen_docs.js             一覧ドキュメント生成
```

外部ライブラリ・ビルド不要。`game/index.html` をブラウザで開くだけで動く（file:// でも可）。

## 2. 実行モデル

- 全シナリオを1本の命令列 `cmds[]` にパースし、`labels{名前: 添字}` で参照する。
- 実行ループ（`runLoop`）は `state.pc` を1つずつ進める。テキストと選択肢でユーザー入力を待つ。
- `runToken` により、ロードやタイトル戻りの瞬間に古いループを確実に停止する（古いループは状態を変更しない）。
- 条件付き行 `?[式]` は、その行の実行直前に評価する。

## 3. 状態（セーブデータ）

```js
{
  pos: { label, offset },       // 現在行（ラベル＋オフセット。シナリオ加筆に強い）
  stackPos: [{label, offset}],  // @call の戻り先
  vars: { 'aff.reny', ..., house, mem, route, 'tmp.*' },
  flags: { F_XXX: true },
  name, chapter, chapterId, scene, hint,
  visual: { bg, chars: {id: {expr, pos}}, still, bgm, letter },
  playTime
}
```

- セーブ枠：オート（章の開始時）、クイック、手動30枠。localStorage（キー接頭辞 `nagi12_`）。
- ロード時は `visual` から画面を復元し、保存した行を再表示する。
- シナリオ加筆でラベル自体が消えた場合は「互換性がありません」と表示して読み込まない。

## 4. システムデータ（周回データ）

```js
{ endings: {id: {date}}, stills: {id: true}, read: {'label:offset': 1},
  hintLevel: {endingId: 1..3}, scenes: {id: true}, chapters: {id: true},
  flagsEver: {F_XXX: true}, config: {...} }
```

## 5. 攻略ヒントシステム（ヒント帳）

| タブ | 内容 |
|---|---|
| いまの状況 | 6人の好感度メーター（目盛り 25／60／80）、家の灯、記憶の断片（◆◇）、ルート予測、「ちづるさんのメモ」（シナリオの `@hint` で更新される今のアドバイス） |
| エンディング攻略 | 27エンディングそれぞれの3段階ヒント。1段階目は常時表示、「もっと詳しく」で2段階目→3段階目（確認ダイアログ付き）。一度見たエンディングは全段階が開く |
| 記憶のかけら | 重要フラグ一覧。このプレイでの入手状況（◆◇）。過去に一度でも入手したものは入手場所と効果、未入手は謎めいたヒント |
| フローチャート | 章ごとのシーン節点（既読は名前、未読は「？」）とシーン回収率 |
| 遊び方 | 操作説明と攻略の基本 |

加えて、**選択肢ヒントマーク**（設定でON/OFF）：各選択肢の右端に、効果から自動生成したマークを表示（●キャラ色＝好感度↑、▼＝↓、■＝家の灯↑、★＝重要フラグ）。

## 6. 画面・操作

- 画面：背景／立ち絵（5位置）／スチル／演出／テキストウィンドウ／手紙ウィンドウ／選択肢／章・エンディングカード／オーバーレイ。
- クイックメニュー：Qセーブ・Qロード・セーブ・ロード・ログ・オート・スキップ・ヒント帳・設定・ウィンドウ非表示・タイトル。
- キーボード：Enter/Space 進む、Ctrl 押している間スキップ、A オート、S/L セーブ/ロード、Q/W クイック、H 非表示、↑ ログ、Tab ヒント帳、Esc メニューを閉じる。ホイール上でログ。
- 設定：文字速度、オート待ち時間、ウィンドウ不透明度、文字サイズ、BGM／SE音量、選択肢ヒントマーク、未読スキップ、システムデータ初期化。
- タイトル：はじめから（名前入力。苗字「汐見」固定、既定「澪」）、つづきから（オートセーブ）、ロード、ヒント帳、ギャラリー、エンディングリスト、設定。

## 7. 素材の差し込み（Codex担当）

- `manifest.js` のパスにファイルを置くだけで表示される。無い場合は背景＝グラデーション＋内容ラベル、立ち絵＝キャラ色のシルエット＋名前・表情名、スチル＝斜線背景＋タイトルと構図指示、音＝無音。
- 音声は `engine.js` の `Audio_`（`playBgm`／`stopBgm`／`se`／`setVolume`）に集約。クロスフェード等はここを拡張する。
- 立ち絵の切り替えアニメ・背景のトランジションは `renderChars`／`setBg` を拡張する。

## 8. 検証ツール

| ツール | 検査内容 |
|---|---|
| `validate.js` | パースエラー、未定義ラベル、未定義の背景・スチル・BGM・SE・立ち絵・表情、未登録/未使用エンディング、フラグの「参照されるが立たない」「立つが参照されない（伏線未回収）」、flags.js未登録、未知の変数、口調ルール違反（ゲルの「貴様」等）、話者名の揺れ、到達不能ラベル、ファイル境界のフォールスルー |
| `simulate.js` | ランダム周回（既定20000回）でのエンディング分布・実行時エラー、エンディングごとの目標探索で全27種の到達手順を発見し `09_攻略チャート_自動生成.md` に出力 |
| `gen_docs.js` | フラグ・エンディング・シーン一覧、素材発注書を生成 |
