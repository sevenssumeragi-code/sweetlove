# 03 分岐とフラグ設計（好感度との関係を含む）

フラグ・エンディングの完全な一覧は `03b_フラグ・エンディング一覧_自動生成.md`、実際に到達を確認した手順は `09_攻略チャート_自動生成.md` を参照。

## 1. パラメータ

| 変数 | 役割 | 主な増減 |
|---|---|---|
| `aff.{reny,hyu,jin,gel,neo,muni}` 好感度 0〜100 | 誰と過ごしたか。ルート選択とHAPPY判定 | 「誰と過ごす？」系の選択 +3〜+6／大事な場面 +5〜+6／拒絶 −1〜−2 |
| `house` 家の灯 0〜100（初期50） | 住人全体のまとまり。「空き家」BADとトゥルー判定 | 朝ごはん・ただいま・待つ +2〜+5／ひとりで飛び出す・誰も呼ばない −2〜−3 |
| `mem` 記憶の断片 0〜7 | 主人公の失われた記憶 | 蝋燭（2章）・缶の星（5章）・夢（5章）・屋根裏の缶（6章）・あおいの声（8章追う／ヒュウ10章）・スケッチ（ヒュウ9章）・十二通目 |
| `route` | 個別ルート | 第八章「初雪の夜」で確定 |
| `sys.endings` | 周回データ（回収済みエンディング数） | トゥルー解放（5以上） |

好感度の目安（ヒント帳のメーターに目盛りとして表示）：

| 値 | 意味 |
|---|---|
| 25 | 第八章でそのキャラのルートを選べる |
| 35〜45 | 三角関係イベントの発生（第十章 40／第十一章 35／第十二章 45） |
| 60 | 三角関係の甘い結末 |
| 80 | HAPPYエンドの条件（他条件と併せて） |

シミュレーションによる各キャラの最大到達値：レニィ91／ヒュウ94／ジンパチ94／ゲル92／ネオ92／ムニ92（どのHAPPYにも10点前後の余裕がある）。

## 2. 分岐の構造

```
序章〜第八章（共通・3月〜11月）
  ├─ 各章の「誰と過ごす？」選択 … 好感度が変わり、場面・スチル・台詞が変わる
  ├─ 各章の「手紙のお願い」への応答 … 重要フラグ（★）
  └─ 第八章「初雪の夜」
        ├─ 家の灯<30 または 全員<25 ─→ BAD「空き家」
        └─ 好感度25以上の相手を選ぶ ─→ 個別ルート（6本）

第九章〜第十二章（個別・12月〜3月）：全ルート共通の骨格
  第九章  九通目 → 星まつり計画（ARCHIVE_2があれば設計図探し）→【ルートA】→ クリスマス → 契約書（全文を読むか）→【ルートB】
  第十章  十通目 → しおさい珈琲（今すぐ話す／待つ）→ ネオの真実（ARCHIVE_3でネオ帰還）→【ルート】
  第十一章 十一通目 → 空の引き出し →【ルート：バレンタイン・約束】→ 二月十七日の夜
            ├─ 屋根裏を見張る（FEB_WARNING）─→ 小火【ルート_small】
            └─ 眠る ─→ 本火事 ─┬─ ひとりで飛び込む ─→ BAD「焔の夜」
                                 └─ 皆を起こす ─→【ルート_big】（ルートBADの分岐点）
  第十二章 ヒュウが十二通目を差し出す → 手紙 →【ルート】→ 三角関係の選択 → エンディング判定
```

## 3. 選択肢の設計原則

1. **違う選択は違う話になる**：「誰と過ごす？」選択は必ず固有のシーン（10〜20行）とスチルを持つ。同じ場面に全員が同じ台詞を言うことはない。
2. **手紙に従う／逆らうが分岐になる**：第八章「追いかけるな」は、従う（HYU_PLATE）と逆らう（AOI_MET）のどちらを選んでも正解で、得られる情報が違う。
3. **罠の選択肢**：第十一章「ムニの隣で、手を握って眠る」は一見いちばん安全だが、ムニは手の中から抜け出してしまう。手紙の「屋根裏に誰も上がらせないで」を字義通りに守る「見張る」だけが小火で済む。
4. **BADは好感度不足ではなく選択で起こる**：各ルートのBADには、明確な「その選択」がある（ヒント帳の第2段階ヒントで示す）。
5. **選択肢ヒントマーク**（設定でON/OFF）：色の●＝そのキャラの好感度↑、▼＝↓、■＝家の灯↑、★＝重要フラグ。

## 6. 三角関係システム

- **発生**：共通ルートの特定の選択（第四章「三人で回ろう」、第五章「ネオも隣に」、第七章「二人の間に飛び込む」）でフラグが立つ。いずれも両者の好感度が一定以上のときだけ選択肢が出る。
- **育成**：個別ルートで、相手でない方の好感度が40以上なら第十章に**三角イベント**（二人の対峙・告白合戦）、35以上なら第十一章に**二つ目のチョコ**が発生し、両者の好感度が伸びる。
- **決着**：第十二章で二人が同時に主人公を見る場面が発生し「〇〇と二人で」／「三人で」を選ぶ。前者は通常の個別エンド判定へ、後者は三角エンド（甘い／苦い）。
- **優先順位**：ジンパチルートではJH（ヒュウ）の判定をGJ（ゲル）より先に行う。

## 7. 周回要素

- 既読スキップ、ギャラリー（スチル74枚）、エンディングリスト（27種）、フローチャート（シーン回収率）、ヒント帳（段階ヒントの開放状況）はブラウザのlocalStorageに保存。
- 一度でも入手した重要フラグは、ヒント帳で入手場所が表示される（周回を重ねるほど攻略が楽になる）。
- エンディング5種回収でトゥルーが解放。
