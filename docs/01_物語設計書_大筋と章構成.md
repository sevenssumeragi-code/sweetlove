# 01 物語設計書 — 大筋と章構成

タイトル：**凪ノ家の十二通（なぎのや の じゅうにつう）**
ジャンル：恋愛ADVノベル（夢小説型・主人公名入力）／ヒューマンミステリー
プレイ時間目安：1周 約4〜6時間、全27エンディング

---

## 1. ログライン

> 会ったこともない祖母から、海辺の洋館と、十二通の手紙を遺された。
> 手紙は毎月一日に一通ずつ届き、まるで未来を知っているかのように、この家で起きることを言い当てていく。
> ――ただし、「すべてを話す」と約束された十二通目だけが、どこにもない。

## 2. 斬新さの核（企画の芯）

| 仕掛け | 内容 | なぜ面白いか |
|---|---|---|
| 死者からの月刊の手紙 | 祖母・千鶴の手紙が毎月一日に届き、その月の「お願い」をする | 章の冒頭に必ず「予告」があり、プレイヤーは手紙の意味を考えながら読む。手紙に従うか逆らうかが分岐になる |
| 予言の正体 | 手紙は予言ではなく、祖母が住人たちを毎日見ていたことの結果 | 超常に見えて、最後は人間の愛情で説明がつく（予想外だが納得） |
| 消えた十二通目 | 「十二通目ですべてを話す」と一通目に書かれているのに、存在しない | 第一章から最終章まで引っ張る最大の謎。犯人は「理由のある裏切り」 |
| 主人公自身が謎の中心 | 15年前の火事の夜、主人公は現場にいた。記憶を失っている | 恋愛相手を攻略するほど、自分の過去が明らかになる |
| 同じ夜が二度来る | 15年前の2月17日と同じ屋根裏で、同じ「缶のプラネタリウム」から火が出る | 過去の悲劇をやり直す形で、各キャラの傷が癒える（または再び開く） |

## 3. 世界と舞台

- **灯凪町（ひなぎちょう）**：海へ転がり落ちる坂の町。古い灯台、神社、港、灯台下のカフェ。
- **凪ノ家**：坂の上の白い洋館（昭和6年竣工）。小さな時計塔があり、針は**2時17分**で止まっている。屋根裏は15年前に焼けた。設計者は英国人建築家アーサー・ブライトン（と伝えられるが証拠がない）。
- 時期：主人公が到着する3月末から、翌年3月の春分の日まで、ちょうど1年。

## 4. 隠された真実（全ルート共通の「正解」）

> すべてのルートで、この真実は変わらない。ルートによって変わるのは「誰がそばにいて、どう乗り越えるか」だけ。

1. **15年前の2月16日**：祖母・千鶴の誕生日に、娘の奏と4歳の主人公が凪ノ家を訪れる（写真あり）。当時の住人は、蝋燭作家の翠川あおい（28）と息子の日向（ヒュウ・7歳）。
2. **2月17日未明（2:17）**：星が見たいと言った主人公のために、ヒュウが母の蝋燭と釘で穴を開けた空き缶で「缶のプラネタリウム」を作り、二人で屋根裏で眺めるうちに眠ってしまう。缶が倒れてカーテンに火が移る。
3. ヒュウは燃え落ちるカーテンから主人公をかばい、右目の周りに火傷を負う。その後、怖くなって押し入れに隠れる。
4. 消防士・**鷹取剛**（ジンパチの父）が屋根裏に突入。主人公を星の窓から屋根へ出し、戻ってヒュウを救出した直後、崩れた梁の下敷きになる。翌日、病院で千鶴に「あの子らは星を見てただけだ。誰のせいにもするな」「甚八に、火を怖がる消防士になれと伝えてくれ。怖がるやつが、一番、生きて帰る」と遺して亡くなる。
5. **あおい**は子どもたちを守るため「私の蝋燭の不始末」と名乗り出る（警察は原因を特定せず）。町の目に耐えきれず、ヒュウを姉に預けて町を出る。
6. **奏**（主人公の母）は、娘が火事の記憶を失ったことを知り、忘れたままでいさせると決める。千鶴もそれに同意し、以後15年会わない。時計塔は2:17で止まったまま、千鶴は毎年2月17日に屋根裏の星の窓で蝋燭を一本だけ灯して、剛を弔う。
7. 千鶴は居場所をなくした若者を下宿人として受け入れ続ける（レニィ、ゲル、ヒュウ、ジンパチ、ムニ）。そのために家を担保に借金を重ねる。
8. 去年の秋、千鶴は病を知り、1年分の手紙（12通）を書く。今年の1月6日に死去。ネオは1月初めから執行者として同居していた。
9. **葬儀の夜、ヒュウが十二通目（宛名「{name}と、日向へ」）を机から持ち出す**。自分宛てでもあるが、開けられないまま画布の裏に隠す。

## 6. 章構成とテンポ設計

- **共通ルート**：序章〜第八章（3月〜11月）。第八章の最後「初雪の夜」で、好感度25以上の相手からルートを選ぶ。
- **個別ルート**：第九章〜第十二章（12月〜3月）。全ルートで同じ「冬の骨格」（クリスマスの契約書／ソラの告白／二月十七日の火事／十二通目）を共有し、その中身を各ルート固有の場面で書き分ける。
- 大事件の間隔：第三章・第六章・第七章末〜第八章・第九章・第十一章（3〜4章ごと、終盤は加速）。
- 事件と事件の間に、必ず1〜3個の日常イベント（食事・遊び・秘密の共有・喧嘩と仲直り）を置く。日常の「この時間が永遠に続けばいい」の直後に絶望を置く（例：第六章の停電の夜のババ抜き→鐘、第九章の七人のクリスマス→契約書）。

## 8. ネオは悪役ではない（設定の厳守）

- ネオは最初から「普通の人」。高圧的な口調は、鳳家で唯一身を守る方法だった。
- 第九章の「裏切り」は、家を守るために自分を差し出した**理由のある自己犠牲**。九通目の手紙「あの子は嘘をつくとき、必ず自分を傷つける嘘をつくから」で事前に予告済み。
- 父・鳳源一郎も悪人ではなく「商売人」。千鶴の元教え子で、最後に「千鶴先生は、私の先生でもあった」と明かす（第八章で時計塔を見上げる伏線）。

## 9. 禁止事項への対応

| 禁止事項 | 対応 |
|---|---|
| ご都合主義 | 家を救う方法（文化財登録）は第二章・第五章・第九章の3段階で証拠を集めた場合のみ成立。集めなければネオは戻らない |
| 突然の性格変更 | 各キャラの変化は、秘密の開示→葛藤→選択の順に段階的。ヒュウの「気取り」は第三章・第五章で少しずつ剥がれる |
| 理由のない裏切り | ネオ（自己犠牲）、ヒュウ（十二通目の持ち出し＝恐怖と、自分宛てでもあったから）、あおい（子どもたちを守る偽証）すべてに理由と伏線 |
| 意味のない死亡 | 死亡はジンパチBAD（父と同じく二人目を助けに戻る＝父の遺言「怖がるやつが生きて帰る」の反転）と共通BAD「焔の夜」（手紙の「ひとりで行かないこと」を破った結果）のみ |
| 伏線未回収 | `tools/validate.js` が「立つが参照されないフラグ」を検出。伏線表（04）で全回収を管理 |
| レニィとムニの血縁 | 設定なし。二人とも青髪なのは偶然で、ムニの髪は母ソラ譲り。第二章の潮干狩りで漁師に兄弟と間違われ、レニィ本人が「ちがうよぉ」と否定、ヒュウが「隠し子説も年齢的に無理」と冗談で明確に打ち消す |
