# 凪ノ家の十二通（なぎのや の じゅうにつう）

> 会ったこともない祖母から、海辺の洋館と、十二通の手紙を遺された。
> 手紙は毎月一日に一通ずつ届き、まるで未来を知っているかのように、この家で起きることを言い当てていく。
> ――ただし、「すべてを話す」と約束された十二通目だけが、どこにもない。

6人の住人との、甘くて少し切ない1年を描く恋愛ADVノベルゲーム（主人公は女性・名前入力式）。

- 攻略対象：レニィ／ヒュウ／ジンパチ／ゲル（同性）／ネオ、家族の絆：ムニ
- エンディング27種（各キャラHAPPY・NORMAL・BAD、三角関係6種、共通BAD2種、TRUE）
- スチル74枚、シーン170以上、本文約10万字、選択肢約90か所
- 攻略ヒントシステム（ヒント帳・3段階エンディングヒント・記憶のかけら・フローチャート・選択肢ヒントマーク）

## 遊び方

`game/index.html` をブラウザで開くだけ（ビルド不要・外部ライブラリなし・オフライン可）。

現在、グラフィックとBGM・効果音は**プレースホルダ**です（背景は内容ラベル、立ち絵はキャラ色のシルエット、スチルは構図指示つきの枠、音は無音）。素材は `docs/08_素材発注書_Codex用.md` のとおり `game/assets/` に置けば自動で差し替わります。

## 開発者向け

```
node tools/validate.js     # 静的検証（参照・素材・フラグ・口調・到達可能性）
node tools/simulate.js     # 全エンディング到達検証＋攻略チャート生成
node tools/gen_docs.js     # 一覧ドキュメント生成
```

シナリオは `game/scenario/*.js`（独自DSL、仕様は `docs/07`）。データは `game/data/*.js`。
